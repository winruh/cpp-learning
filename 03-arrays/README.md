# 03 — Arrays / Массивы

| File | What the code does | Что делает код |
|---|---|---|
| `array_basics.cpp` | Declares `int chisla[4]` with an initialiser list, prints all four elements by index, writes `99` into index 2, prints the sum of elements 0 and 3 | Объявляет `int chisla[4]` со списком инициализации, печатает все четыре элемента по индексам, записывает `99` в индекс 2, печатает сумму элементов 0 и 3 |
| `array_sum.cpp` | Declares `int chisla[5]`, walks it with a `for` loop, prints each element and accumulates a running sum | Объявляет `int chisla[5]`, обходит его циклом `for`, печатает каждый элемент и накапливает сумму |
