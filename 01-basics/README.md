# 01 — Basics / Основы

| File | What the code does | Что делает код |
|---|---|---|
| `hello.cpp` | Prints three lines with `std::cout`, one of them in Cyrillic | Печатает три строки через `std::cout`, одна из них на кириллице |
| `about_me.cpp` | Prints five lines, using the `std::` prefix without `using namespace std` | Печатает пять строк, с префиксом `std::` без `using namespace std` |
| `variables.cpp` | Declares a `std::string` and an `int` with initial values and prints both | Объявляет `std::string` и `int` с начальными значениями и печатает оба |
| `data_types.cpp` | Declares `double`, `char` and `std::string`; reads the string with `std::cin`, prints all three | Объявляет `double`, `char` и `std::string`; читает строку через `std::cin`, печатает все три |
| `division_and_types.cpp` | `double a = 7`, `int b = 2`, prints `a / b` | `double a = 7`, `int b = 2`, печатает `a / b` |
| `age_calculator.cpp` | Reads two years with `std::cin`, subtracts one from the other, prints the result | Читает два года через `std::cin`, вычитает одно из другого, печатает результат |
| `greeting.cpp` | Reads a `std::string` and an `int` in one program, prints both in formatted output | Читает `std::string` и `int` в одной программе, печатает оба в форматированном выводе |
