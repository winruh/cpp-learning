# 02 — Control Flow / Ветвления и циклы

| File | What the code does | Что делает код |
|---|---|---|
| `adult_check.cpp` | Reads an age, prints one of two messages via `if` / `else` | Читает возраст, печатает одно из двух сообщений через `if` / `else` |
| `compare_number.cpp` | Reads a number, compares it with 3 in three branches: `if` / `else if` / `else` | Читает число, сравнивает с 3 в трёх ветках: `if` / `else if` / `else` |
| `even_or_odd.cpp` | Reads a number; a separate branch for the value `2` comes before the general `% 2` parity check | Читает число; отдельная ветка для значения `2` стоит перед общей проверкой чётности через `% 2` |
| `while_loop.cpp` | Prints 1 to 10 with a `while` loop and a manually incremented counter | Печатает от 1 до 10 циклом `while` с вручную увеличиваемым счётчиком |
| `for_loop.cpp` | Prints 1 to 10 with a `for` loop | Печатает от 1 до 10 циклом `for` |
| `even_odd_loop.cpp` | Loops from 1 to 20 and marks each number `even` or `odd` — an `if` inside a loop body | Цикл от 1 до 20, каждое число помечается `even` или `odd` — `if` внутри тела цикла |
| `guess_the_number.cpp` | `srand(time(0))` + `rand() % 100 + 1`, a `while` loop that repeats until the user's input matches, hints "malo" / "mnogo", and an attempt counter | `srand(time(0))` + `rand() % 100 + 1`, цикл `while` до совпадения с вводом пользователя, подсказки «malo» / «mnogo», счётчик попыток |
